# Finance-Risk-Insights
Power BI dashboard project focused on finance risk analysis, investment planning, and trend exploration.

## 🛠️ Tools Used
- Power BI
- Excel / SQL (for data prep)
- DAX
- Power Query

## 🎯 Project Objectives
1. Analyze risk management focusing on current financial trends.
2. Perform risk analysis with an intuitive, visually-rich dashboard.
3. Develop a strategic view of investment trade-offs and opportunities.

## 📁 Project Structure
- `data/`: Contains the raw/cleaned dataset used
- `powerbi_dashboard/`: PBIX file with dashboard visuals
- `images/`: Dashboard preview screenshots

## 📊 Dashboard Insights
- Portfolio performance over time
- Risk heatmap based on financial metrics
- Sector-wise or investment-type distribution
- Trend analysis for key financial KPIs

## 📌 Future Scope
- Add real-time data connection using APIs
- Enhance with forecasting and What-If analysis
